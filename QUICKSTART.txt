GALACTIC RACER HOSAS/HOTAS BRIDGE v1.92 BETA — QUICK START
by JaffaQuake and Mars

INSTALLATION
1. Extract the ZIP.
2. Double-click Install.cmd.
3. Launch the installed app.

1. CHOOSE INPUT API
- Existing users upgrading from an older build will remain on WinMM compatibility by default.
- Auto: uses DirectInput first and falls back to the matched WinMM device when possible.
- DirectInput: exposes X/Y/Z, Rx/Ry/Rz, Slider 1 and Slider 2.
- WinMM: preserves the older six-axis path that has been stable with the original VKB setup.

If a throttle axis is missing in WinMM, try DirectInput and Refresh Devices.

2. CHOOSE CONTROL MODE
HOSAS / Podracer Style
- Choose Left Stick and Right Stick.
- Click Detect Left and push the left control forward.
- Click Detect Right and push the right control forward.
- Optional: enable Hybrid Preserve Thrust.

HOTAS / Traditional Steering
- Choose a throttle and its axis. Throttle maps to Xbox RT / forward only.
- Choose a flight stick and X/Y axes. The stick maps directly to Xbox Left Stick X/Y.
- DirectInput mode adds rotation and slider axes for broader throttle support.

3. OPTIONAL HIDHIDE / DOUBLE-INPUT PROTECTION
If the physical flight controller is also controlling the game directly:
- Install HidHide from the official Nefarius project.
- Click HidHide Setup in this app.
- The mapper will try to allowlist itself and open HidHide Configuration Client.
- In HidHide, select the physical flight devices you want hidden from games and enable hiding.
- Reconnect the hidden devices so the change takes effect.

HidHide is optional. v1.92 Beta does not automatically hide any device.

4. BUTTONS / ON-FOOT / PEDALS
- Learn Xbox buttons and D-pad directions in the mapping section.
- On-Foot controls can use learned Buttons -> WASD or the experimental DirectInput thumbstick path.
- Pedals can provide Fine Steering, Move Camera, or left/right keyboard keys.

5. START MAPPING
- Click Start Mapping to create the virtual Xbox controller.
- Click Stop Mapping when finished; the virtual Xbox controller is removed.
- Settings are saved automatically.

WINDOW SIZE
- The window is resizable and maximizable.
- Controls remain their original size and position.
- When the window is smaller than the content area, use the scroll bars to reach hidden sections.
